# The professional rubric

Score each line 0–5 with evidence (file, screenshot, measurement, link).
0 = missing · 1 = present but broken · 2 = works, rough · 3 = solid · 4 = polished · 5 = best-in-class vs. the benchmark competitor.
Skip lines that don't apply to the platform (mark n/a). Rescore the same lines after the level-up.

## Product
| line | what 4–5 looks like |
| --- | --- |
| Core flow | critical flow is fast, reliable, and handles edge cases (empty input, offline, double tap) |
| Depth | the differentiator from the competitor gap is clearly felt within the first session |
| Quality | tests cover the critical flow; no console/runtime errors; typecheck and lint clean |
| Performance | web LCP < 2.5 s and Lighthouse perf ≥ 90 · app launches < 1 s, 60 fps · game holds 60 fps on mid devices |
| Measurement | analytics events for each step of the critical flow, with a privacy-respecting setup |

## Experience
| line | what 4–5 looks like |
| --- | --- |
| First run | a new user reaches the "aha" in < 60 s without instructions |
| Visual craft | consistent type scale, spacing, colour tokens, icons; no misalignment |
| States | designed empty, loading, error and success states; no dead ends |
| Accessibility | contrast AA, keyboard/focus, labels, Dynamic Type / reduced motion respected |
| Copy | clear, in brand voice, no placeholder or jargon; microcopy guides the next action |
| Mobile | flawless at 375 px / small phones; touch targets ≥ 44 pt |

## Market
| line | what 4–5 looks like |
| --- | --- |
| Positioning | one sentence a buyer repeats; names the buyer and the gap vs. competitors |
| Front door | landing page / store listing / portal page that converts: hero, proof, benefits, demo, CTA |
| SEO / ASO | titles, meta, OG image, keywords, structured data / App Store keywords |
| Launch kit | channel-specific posts for 2–3 named communities, demo GIF/video script, press line |
| Trust signals | privacy, terms, contact, about, real screenshots; no fake social proof |

## Sell
| line | what 4–5 looks like |
| --- | --- |
| Pricing | tiers or single price anchored on cited competitor prices, with a reason for each limit |
| Offer | clear value stack, trial/guarantee, honest urgency |
| Purchase path | test-mode checkout or StoreKit works end to end and unlocks the paid tier |
| Capture | email/waitlist capture on the front door and in-product |
| Lifecycle | welcome + follow-up emails written; upgrade prompts at the value moment |
| Unit economics | price minus cost to serve per customer is positive, shown in pricing.md |

## Pitch
| line | what 4–5 looks like |
| --- | --- |
| Story | problem → customer → solution → why now → gap, in one page |
| Deck | 10–12 slides, one takeaway headline each, speaker notes |
| Demo | 2-minute live demo script that hits the "aha" |
| Evidence | real traction, or an honest dated plan to get the first numbers |
| Metrics | 3–5 stage-right metrics, instrumented, with targets |
| Ask | amount, instrument, use of funds, milestones it buys |
