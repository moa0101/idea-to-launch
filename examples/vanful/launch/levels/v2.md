# v2: Works → Credible

**Step choice:** the user gave no next step, so the challenger picked one. Credible comes
before Sellable. Nobody pays for or shares a game they didn't understand in the first minute,
and a game with no front door can't be found.

**Headline:** *a guided first delivery that teaches the door rule by doing it.*

## Items

| # | track | item | acceptance check |
| --- | --- | --- | --- |
| 1 | Experience | Guided first delivery: a scripted 2-stop round with coach marks (drag here → rotate → load the first stop by the door → tap houses → drive); skippable; offered once, replayable from the title | A new player finishes the tutorial in < 60 s and sees "Door clear ✓" without reading other text |
| 2 | Product/SEO | HTML front shell: semantic h1/tagline/how-to/noscript under the canvas; zoom allowed; Phaser lazy-loaded after first paint; OG + Twitter meta + OG image; robots.txt; web manifest | Lighthouse a11y ≥ 90, SEO ≥ 90, performance scored (not n/a) and ≥ 90 desktop |
| 3 | Experience | Keyboard parity: Q/E rotate while dragging, Space/Enter = Plan route / Drive / Next, Z = undo last parcel; Undo button in pack phase; `prefers-reduced-motion` disables shake/bob | Every phase can be advanced from the keyboard; undo returns the last parcel to the tray |
| 4 | Trust | About screen: what it is, how it plays, privacy note (no account, no data leaves the device, best score in localStorage), credits, version | Reachable from the title; states exactly what is stored |
| 5 | Measurement | Local event log `track()` on shift_start, tutorial_step/done/skip, pack_done, route_set, round_done, shift_over, play_again, copy_score; stored locally (last 500), viewable with `?stats`; a provider can be plugged in later (hard stop: needs an account) | Playing a shift records each event, and `?stats` shows the counts |
| 6 | Market | `go-to-market/`: positioning v2, itch.io + CrazyGames page copy, tags, screenshot/capsule brief, 30 s trailer script, launch posts for named channels (drafts) | Each claim is true of the build; no invented reviews or numbers |
| 7 | Craft | Fix the tape stripe crossing letters and the stray dot on 2×2 parcels | Visual check |

## Not in this level (deliberately)
Music, online leaderboard, daily seed, monetisation (Sellable), pitch deck (Fundable), deploying (hard stop).

## Result: Works → **Credible (provisional)**

Credible exit criteria:

| criterion | result | evidence |
| --- | --- | --- |
| First run reaches the "aha" in < 60 s with no help | ✅ automated / ⏳ human | Guided delivery completes in 7–9 s of automated play (Playwright, desktop + Pixel 7). Real-human time is still unmeasured, so see the playtest. |
| Polished empty, loading and error states; no dead ends | ✅ | Coach handles wrong packs ("A B parcel blocks the door"); engine-load error message in HTML |
| Accessibility AA | ✅ | Lighthouse a11y 76 → **100**; zoom allowed; keyboard Q/E/Z/Space/Enter; reduced motion respected |
| Lighthouse ≥ 90 perf/a11y/SEO | ✅ | **100/100/100/100** mobile and desktop (first visit) |
| Front door with a sharp positioning line | ✅ | HTML front door + `go-to-market/positioning.md`, `store-pages.md` (drafts) |
| Privacy / terms / contact | ⚠️ | Privacy ✅ (About screen). Terms n/a (no accounts or payments). **Contact route missing: needs your support email or page.** |
| Analytics on the critical flow | ✅ (local) | 12 events, viewable with `?stats`; no cross-player totals until a provider is chosen (hard stop) |
