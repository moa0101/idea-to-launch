# v5: public launch kit (Sellable → first public evidence)

**User's step:** a public launch kit: itch.io zip + page, CrazyGames/Poki pack, gameplay video/GIF, rule-checked posts.
Posting and submitting stay with the owner.
**Headline:** *upload-ready on two portals, and every player is counted by where they came from.*

**Challenge:** the kit alone would have shipped a zip that shows a blank page on itch (gap 1) and copy that contradicts the
privacy notice (gap 2). Both are fixed first. Gap 3 is added because a launch you can't attribute isn't evidence.
