# v2 plan: Works → Credible (for Claude Code users)

**The user's step:** "the idea to launch", meaning level up the pack itself, for Claude Code users.

**Challenge:** the pack's biggest problem isn't missing features. The front door sends people to a command
that doesn't exist (`/levelup`) and shows no proof. Fixing the front door and backing it with the real Vanful
run comes before any new skill.

## Headline
**A README a stranger trusts in 10 seconds:** a working quickstart, the live result, a GIF, and the real
v1 → v5 scorecard, all backed by a full example in the repo.

## Items and acceptance checks

1. **Front door v2** (`README.md`, `.claude-plugin/*.json`)
   - every slash command in the README matches a skill name (checked by the validator)
   - the version is the same in the README badge, `plugin.json` and `CHANGELOG.md`
   - a live demo link and a GIF from the real game sit above the fold
   - the v1 → v5 table uses numbers copied from `examples/vanful/launch/levels`
2. **The Vanful example at v5** (`examples/vanful`)
   - the tracked v5 source plus `launch/levels/v2–v5`
   - no local paths, secrets or personal emails
   - `npm ci && npm test && npm run build` passes in the example
3. **Skill checks + CI** (`scripts/validate.mjs`, `.github/workflows/ci.yml`)
   - fails on a bad skill header, a broken relative link, mismatched versions, a README command with no skill,
     an absolute `/Users/` path or a secret-looking string
   - passes on the repo
   - CI also runs the example's tests
4. **Changelog, troubleshooting, updating** (`CHANGELOG.md`, README sections)
5. **Measurement + launch kit** (`scripts/stats.sh`, `launch/posts.md`)
   - stats prints stars, 14-day views and clones from `gh api`
   - posts for r/ClaudeAI, Show HN, an awesome-claude-code PR and the official marketplace submission, with
     each venue's rules noted
   - drafts only

## Deliberately not in this level
- New skills, or support for other agents (Codex, Cursor and so on).
- Pricing, paid tiers and pitch: Sell and Pitch aren't this audience's questions.
- Pushing, tagging a release, or submitting to marketplaces and lists. Those are the user's call.
