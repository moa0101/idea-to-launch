# idea-to-launch: the product

**What it is:** a Claude Code plugin with 7 skills.
- `/launch <idea>` asks at most 5 questions, then validates the idea, brands it, writes a spec, and builds a working MVP with a real backend. It runs and verifies the MVP before handing it over.
- `/launch-levelup` takes each next version up a ladder: Works → Credible → Sellable → Fundable → Scalable.

**Who it's for:** Claude Code users (indie developers and technical founders) who have an idea and want a running, tested product instead of a plan.

**The job:** "Turn my one-line idea into something I can click, show and ship today."

**Why now:** Claude Code skills and plugins can now package a whole method (panel, brand, builder, verifier) that installs in one command.

**Gap vs. the alternatives:**
- **Generic dev-method packs** (obra/superpowers): great engineering process, but no validation, brand or go-to-market.
- **Prompt-to-app tools** (Bolt, Lovable, v0): fast web prototypes in a hosted editor; the panel, native apps and go-to-market aren't their focus.
- **Founder-advice packs** (founder-skill): validation and documents, but no build.

Among the packs and tools compared here, idea-to-launch is the one that goes from idea to a verified MVP across web, iOS, macOS and games, and then keeps levelling it up, including the store page, launch posts and pitch.

**Proof so far (real):** [Vanful](https://vanful.vercel.app), a browser puzzle game. One `/launch` run, then 4 level-ups (v2–v5), are live and documented in `examples/vanful`.
